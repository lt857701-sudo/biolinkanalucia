# Ana Lúcia Estética Corporal - Bio Link

Página de bio link profissional para **Ana Lúcia Estética Corporal** - Estética avançada, depilação a laser, pós-operatório, drenagem e PEIM em **Barra do Garças – MT**.

## 🚀 Deploy na Vercel

Este projeto é um site estático otimizado para deploy na Vercel.

### Passo a passo:

1. Faça push deste repositório para o GitHub
2. Conecte seu repositório na [Vercel](https://vercel.com)
3. Importe o projeto - a Vercel detectará automaticamente que é um site estático
4. O deploy será feito automaticamente a cada push

### Estrutura do projeto

```
biolink-ana/
├── index.html              # Página principal
├── package.json            # Configuração Node
├── vercel.json             # Configuração Vercel
├── manifest.json           # PWA Manifest
├── README.md               # Este arquivo
├── server.js               # Servidor local Node.js
├── start-server.vbs        # Script para iniciar servidor no Windows
├── images/
│   ├── capa.png            # Imagem de capa da clínica
│   ├── perfil.png          # Foto de perfil da Ana Lúcia
│   └── favicon.svg         # Favicon da marca
└── assets/images/
    ├── capa.png            # Cópia da imagem de capa
    └── perfil.png          # Cópia da foto de perfil
```
